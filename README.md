# Unity Demo

A Unity playground for experiments and demos built while learning game development. A scratch project for trying mechanics, testing ideas, and validating workflows before promoting them into a fuller project.

## Overview

This is intentionally a sandbox â€” a place to prototype quickly. It holds a Unity project skeleton (package manifest and project settings) where experiments are staged, rather than a single polished game.

## Contents

```
Packages/          # Unity package manifest (manifest.json, packages-lock.json)
ProjectSettings/   # Full Unity project configuration
.vsconfig          # Visual Studio / Rider configuration
```

## Purpose

Used for:
- Trying mechanics and physics setups
- Testing Unity tooling and workflows
- Validating ideas before committing them to a serious project

For finished exercises, see `rolling-ball` (physics fundamentals) and `GamesTest` (mechanic prototyping).

## Tech Stack

- Unity
- C#

## Running

Open the folder in Unity Hub with a matching Unity version (see `ProjectSettings/ProjectVersion.txt`).
